# fase1_exploracao

Esta pasta contém código explorado e adaptado a partir do repositório
[jirifilip/pyARC](https://github.com/jirifilip/pyARC), uma implementação de
referência do algoritmo CBA (Classification Based on Associations).

O propósito desta fase é exclusivamente de **aprendizado**: entender o
funcionamento interno do CBA, suas etapas de geração de regras de associação
(CBA-RG) e de construção do classificador (CBA-CB), antes de partir para a
implementação própria.

Nada nesta pasta deve ser considerado autoria do bolsista de Iniciação
Científica. A implementação original, feita do zero, está na pasta
`fase2_implementacao/`.
